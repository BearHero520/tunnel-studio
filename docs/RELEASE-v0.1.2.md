# Tunnel Studio v0.1.2 · 管理界面挂载修复

v0.1.1 的管理界面被错误地追加到 KANO 功能列表的折叠容器中。宿主只按内部 `.collapse_box` 计算高度，并设置 `overflow:hidden`，导致插件内容被裁剪，即使功能列表展开也可能看不到。

v0.1.2 将界面放在整个功能列表区域之后，独立于折叠容器。刷新后可在 KANO 首页功能列表下方看到 **Tunnel Studio** 管理面板。关闭功能列表也不会隐藏面板。

## 更新

在 KANO 插件管理删除旧的 Tunnel Studio 插件项，导入新版 `tunnel-studio.js`，保存并刷新。删除的是网页插件项，不需要卸载设备后端、重启设备或调整 root。不要同时保留多个版本，因为先执行的旧版本会阻止新版重复创建界面。

## 验证范围

新增包含真实宿主嵌套结构与高度裁剪规则的浏览器测试，覆盖桌面、手机、菜单开合、面板交互和宿主按钮。继续验证 HTML script 提取导入、原有管理流程与桥接、恢复和 Go 测试。

这仍是预览版。浏览器结构测试不等于用户设备上的认证会话实测；真实系统 TUN、LAN 代理和 BE88U 公网握手仍未完成验证。v0.1.0 的故障恢复步骤见上一版发行说明。
