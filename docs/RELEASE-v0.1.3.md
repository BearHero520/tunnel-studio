# Tunnel Studio v0.1.3 · ARM64 识别修复与简洁界面

修复 KANO 执行通道已返回 uid=0、但 uname 返回 armv8l 时被错误拒绝安装的问题。现在结合 Android 的 ro.product.cpu.abilist64 属性判断 ARM64 支持。权限不足、无法解析身份和无法确认架构分别提示，诊断页也显示 64 位 ABI。

界面改为简洁布局：移除大面积绿色卡片、侧栏、装饰标记和宣传文案，采用紧凑横向标签、透明背景、细分隔线与青绿色操作按钮。继承 KANO 的文字颜色，并适配明暗主题。管理面板仍位于功能列表下方，不受折叠菜单裁剪。

## 更新

在 KANO 插件管理删除旧 Tunnel Studio 插件项，导入 v0.1.3 的 tunnel-studio.js，保存并刷新。确认标题版本为 v0.1.3 后，在“版本与恢复”点击“安装 / 更新内置资源”。网页插件更新不会自动启动隧道。

已有可用 KANO 特权执行通道的设备直接复用该通道，不要求另行获取 ADB root 或安装 VPN 应用。此版本仍需要宿主具备管理系统隧道的权限，不是完全无特权设备的 Android VpnService 实现。

## 验证

7 项 Node 测试通过，包括 root + armv8l + arm64-v8a、非 root、纯 32 位或不兼容 ABI、异常输出。浏览器安装流程使用 armv8l 模拟结果，验证内置资源解压、上传、安装调用和完成反馈；原有管理流程、HTML 导入、折叠菜单、手机/桌面明暗主题验证通过。Go 测试与 go vet 通过。

U30 Air 的 KANO 诊断由用户提供：uid=0、armv8l、TUN 节点存在；另通过 ADB 读取同一设备的 64 位 ABI 为 arm64-v8a。真实 KANO 登录会话中的安装及系统隧道、路由和公网握手仍待复测，不将模拟安装结果视为真机安装成功。
