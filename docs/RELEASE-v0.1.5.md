# Tunnel Studio v0.1.5 · 配置加载与诊断改进

刷新 KANO 页面后，插件现在自动读取设备状态及已保存配置，避免空编辑框让人误以为配置丢失。未保存修改增加离页提醒；清空编辑器不删除设备配置，并阻止启动与当前编辑不一致的旧配置。配置不保存到浏览器存储。

诊断增加设备和浏览器采集时间、耗时、接口收发及丢包计数、防火墙规则命中计数、后台状态读取错误。导出文件带采集时间，明确提示导出的是上次采集的快照。未启用的规则链可能出现在 firewallReadErrors 中，不代表对应协议必须启用。

## 更新

停止 Tunnel Studio，替换 KANO 中的旧插件 JS，保存并刷新；确认标题 v0.1.5 后点击“安装 / 更新”，以更新设备诊断后端。保留设备已保存配置，不自动启动隧道。

## 验证与限制

配置重新载入与离页提醒回归测试、现有浏览器流程和 Go 测试通过，已构建 Android ARM64 资源。

**本版没有修改代理路由或 DNS 策略。用户反馈的百度无法访问、持续运行后断网仍未定位或修复，不应将本版视为稳定性修复。** 没有新增真机端到端或持续联网验证，也没有吞吐改进结论。
