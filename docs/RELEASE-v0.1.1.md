# Tunnel Studio v0.1.1 · 导入修复预览版

修复 v0.1.0 缺少 HTML script 封装的问题。KANO 将插件文件当作 HTML 解析后提取 script 执行，裸 JavaScript 不会生成管理入口。新增兼容 HTML 导入和直接 JS 加载的封装，并在构建时拒绝会提前截断 script 的内容。

浏览器回归已复现 v0.1.0 无管理入口，验证 v0.1.1 正常显示、宿主按钮可用、重复导入不重复创建入口，以及原有桌面/手机管理流程。Go 测试、静态检查及 Node 桥接测试通过。

## 已导入故障版本时

先删除旧插件，再导入 v0.1.1。如果 KANO 插件管理仍能操作，删除 `tunnel-studio.js` 对应项并保存、刷新即可。

若页面无法操作，在**原来已经登录的 KANO 网页**按 F12 打开 Console，粘贴源码包 `tools/recover-v0.1.0.js` 的完整内容并执行。该脚本调用 KANO 自己的插件读写接口，仅移除 SHA-256 与原始 v0.1.0 完全匹配的插件块；保留其他插件，校验写回结果后提示刷新。不要在 GitHub 下载页面运行，不要将脚本作为插件导入。若提示未登录、哈希不匹配或列表变化，停止并反馈错误，不要清空插件列表或应用数据。

恢复脚本已通过模拟接口测试；尚未在用户的已认证设备会话实际执行。界面卡顿是否完全消失仍需设备复测。此次没有中断现有 wg0，也未修改设备路由、防火墙或应用数据。

这仍是联调预览版：实际系统 TUN、LAN 代理、BE88U 公网握手及启动恢复尚未完成设备验证。此前的 U30 Air 加密测试使用内存 TUN 与真实本机 UDP，不等于完整代理验证。
