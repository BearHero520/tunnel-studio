# Tunnel Studio v0.1.4 · 流量接管与双栏管理

之前只创建隧道，空 sources 不会接管上网流量。v0.1.4 新增“本机 + 热点”“仅本机”“仅热点”自动代理模式：处理专属策略路由、按掩码打标、转发放行、IPv4 NAT，以及配置中的 TCP/UDP DNS。排除隧道传输、服务端地址和局域网地址，保留管理访问。规则逐步记录逆操作，普通失败或停止时清理；超时等无法确定的状态保留事务记录。

IPv6 默认阻止所选范围的外网直连，保留链路本地、局域网和隧道传输；可选择 NAT66 或仅热点的 IPv6 路由模式。NAT66 需要内核支持；IPv6 路由模式要求服务器覆盖热点前缀并有回程路由。此版本没有自动把 IPv6 转为 IPv4 的能力。

桌面改为顶部操作栏、左侧配置和右侧状态/诊断。高级网络与导入选项折叠，手机自动单栏。显示实际运行范围，明确标注仅隧道状态。

## 更新步骤

先刷新并停止旧 Tunnel Studio 隧道，替换网页插件、保存刷新，再点击“安装 / 更新”。之后**读取设备配置，将代理范围改为“本机 + 热点”，保存并启动**。旧配置不会自动接管网络；仅更新 JS 而不安装新后端也不会增加网络功能。U30 Air 热点接口已只读核对为 br0。

DNS 按配置生效，须包含在 AllowedIPs 内；无可用 DNS 时给出警告。全局代理需要对应的默认 AllowedIPs。选择“阻止外网 IPv6”可先验证 IPv4 路径；它会阻止所选范围内 IPv6-only 外网访问。

## 测试边界

配置、路由计划、所有步骤的故障注入及逆序清理计划测试通过。Android x86_64 模拟器实际执行 IPv4/IPv6 路由、防火墙规则、NAT66 与删除命令，并验证标记路由指向临时 TUN；流量入口替换成未挂接测试链，没有接管模拟器真实流量。临时接口、规则和文件已清理。

浏览器验证旧配置保留仅隧道模式、切换自动模式后的保存确认、未保存修改阻止启动、双栏及手机布局、KANO HTML 导入和折叠菜单兼容。

未修改 U30 Air 的活动网络或配置。v0.1.4 尚未在用户已认证 KANO 会话执行完整安装与公网代理测试，不能承诺已解决所有设备环境问题。v0.1.3 用户诊断证实隧道创建和握手，但未启用接管。
